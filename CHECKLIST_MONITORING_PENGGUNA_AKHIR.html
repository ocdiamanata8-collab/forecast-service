Aturan (adaptasi dari 7 aturan master)

  1. Monitoring hanya konsumen API — kode algoritma tidak masuk repo platform.
  2. Nama field dikunci lewat test + adapter — ubah kontrak → edit adapter, bukan seluruh UI.
  3. Timestamp selalu +08:00 (WITA), jangan dikonversi ke zona browser.
  4. Riwayat forecast tidak ditimpa — platform menyimpan per generated_at.
  5. Forecast dijadwalkan, tidak dihitung ulang saat paint — baca hasil scheduler + cache.
  6. model_version + generated_at selalu tampil agar regresi akurasi telusur.
  7. Kegagalan harus terlihat, bukan angka basi — setiap state gagal punya pesan.

Kriteria keluaran

Platform menampilkan forecast pengguna akhir dari API sungguhan (lengkap label model version + waktu pembuatan), menyembunyikan garis di luar jendela horizon, membedakan “menunggu pengamatan” dari “data kosong”, menampilkan kegagalan dengan pesan jelas tanpa angka basi, lulus siklus E2E data nyata + simulasi kegagalan, dan siap go-live bertahap.
